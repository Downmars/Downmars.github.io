# 翻案集：设计、写作与验证

2026年9月27日，已在当前 Hugo 0.145.0 / PaperMod 项目中实现。首条内容由旧文《克隆 Arch Linux》迁入，整理为[换主机时，我为什么选择迁移 dotfiles](../content/zh/thoughts/2025_12_09-clone_your_archlinux/index.md)。验证样例只生成在临时目录。

## 页面设计

入口为 `/zh/thoughts/`，沿用现有导航、字体和明暗主题。内容区域最大736px，桌面左侧显示日期、右侧显示正文；600px以下改为单列，日期位于正文上方。记录之间用留白和细线分隔。

时间流按发布日期倒序，每页10条，直接显示正文。只有作者主动写入 `<!--more-->` 才截断并显示“阅读全文”。每条有固定链接，标题可空，标签和关联文章选填。标题为空时，搜索、网页标题、RSS和分享元信息使用日期加正文开头，详情正文不重复显示自动标题。

写作时尽量控制在几十到一两百字。内容较长或涉及多个问题时，优先把详细内容写入 `content/zh/posts/` 的正式文章，thoughts 保留能独立读懂的简短引子，并在正文中链接到文章实际页面。`<!--more-->` 只控制列表展示，不能替代内容取舍；具体写法见[个人博客写作指南](blog-writing-guide.md)。

图片沿用Markdown写法。单图保持比例，多图可排成两列。点图打开原图查看器，只在当前记录内切换，支持方向键、Escape关闭及关闭后恢复焦点；禁用JavaScript时，图片链接仍可直接打开原图。

详情页保留返回入口、日期、正文、关联文章、标签和简洁许可链接。Giscus仅在详情页挂载，沿用pathname关联讨论。短记录不显示目录、字数、阅读时长、上下篇和分享按钮。

## 新建与发布

在仓库根目录运行（需要工作流指定的Hugo版本）：

```sh
TZ=Asia/Shanghai hugo new content --kind thoughts thoughts/2026_09_27-a-short-note
```

命令会创建 `content/zh/thoughts/2026_09_27-a-short-note/index.md`。当前中文是默认语言，命令路径不要再加 `zh/`。日期取执行时刻并使用 `+08:00`，模板默认 `draft: true`。目录名中的日期应随实际创建日期填写。

```text
content/zh/thoughts/
├── _index.md
└── 2026_09_27-a-short-note/
    ├── index.md
    ├── photo.jpg
    └── another.jpg
```

正文示例只是格式说明：

```markdown
---
title: ""
date: 2026-09-27T12:00:00+08:00
draft: true
---

这里写一件想留下来的小事。

![图片的替代文本](photo.jpg "可选的图片说明")
```

图片与正文同目录即可，模板会解析到这条记录的资源地址，列表、详情和RSS都能引用。把多张图片写在连续几行，中间不留空行，即可形成两列图片组；组内不要混排普通文字。不同段落的单图仍按单图显示。

可选字段：

```yaml
title: "一个明确的小标题"
tags: ["已有标签"]
related: ["/posts/2026_03_15-RSS"]
lastmod: 2026-09-28T12:00:00+08:00
comments: false
```

`related`填写Hugo内容路径，不是公网URL；不存在的关联页面会使构建报错。站外链接直接写在正文。作者默认为Downmars，许可默认为CC-BY-NC-4.0，需要时可在记录中覆盖。

准备公开时改为 `draft: false`，检查实际发布日期，然后通过现有Git与Actions流程发布。未来日期和草稿仍被正式构建排除。已发布记录保持目录名和地址稳定；观点变化可追加注明日期的补记，并更新 `lastmod`，或者发新记录回链旧记录。

## 与现有站点的关系

| 入口 | 实际行为 |
| --- | --- |
| 墓志铭、故纸堆、文章上下篇 | `mainSections: [posts]`，继续以文章为范围。 |
| 翻案集 | 独立时间流、单条页和分页；原 `/zh/thoughts/search/` 跳转至栏目页。 |
| 寻章句 | 同时检索文章和短记录，后者标注“翻案集 · 短记”；特殊字符按文字渲染。 |

| 翻案集RSS | `/zh/thoughts/index.xml`，包括完整正文和绝对图片地址。 |
| 标签页 | 可以同时列出文章与短记录，无标题短记录使用同一自动标题。 |
| 首页 | 保留现有个人主页。 |
| 英文导航 | 暂时隐藏无对应内容的Thoughts入口。 |

联调时发现现有 `/zh/search/` 和 `/en/search/` 是自动生成的栏目页，虽渲染搜索框却未加载搜索脚本。已将搜索元信息移至 `_index.md`，保留原 `/search/search/` 地址的跳转。还修正了公共页头注释残留的 `-->` 字符，以及Giscus首次加载时对明暗主题的判断。
